# Rubium — экосистема подготовки к ЕГЭ/ОГЭ

Платформа для подготовки к экзаменам по математике и информатике.
Тренажёр, рабочая тетрадь, кастомные варианты и сообщество.

## Основные возможности

### Тренажёр

- Задания из открытого банка ФИПИ
- Мгновенная проверка ответа и разбор
- AI-подсказки (направляющая мысль, не ответ)
- Встроенный редактор кода с запуском Python
- Поддержка LaTeX для формул

### Кастомные варианты

- Сборка варианта из нужных номеров заданий
- Полный вариант ЕГЭ/ОГЭ с таймером
- Автопроверка и результат в баллах

### Ежедневные задания

- Подборка из 5-10 заданий каждый день
- Микс на основе слабых тем
- Стрик дней и XP за выполнение

### Статистика

- Личная: график прогресса, точность по темам, время занятий
- Глобальная: рейтинг среди всех учеников

### Рабочая тетрадь

- Markdown-редактор с рендерингом (формулы, код, изображения)
- Ведение конспектов, решений, лайфхаков
- Автосохранение в облаке

### Сообщество

- Публикация тетрадей
- Поиск по предмету, теме, автору
- Рейтинг на основе оценок

## Предметы

- Математика (ЕГЭ, ОГЭ)
- Информатика (ЕГЭ, ОГЭ)

## AI

- Провайдер: DeepSeek (основной), OpenAI (фолбэк)
- Подсказки к заданиям
- AI-проверка развёрнутых ответов и кода

## Технологии

| Компонент        | Стек                       |
| ------------------------- | ------------------------------ |
| Фронтенд          | HTML, CSS, Vanilla JS          |
| Бэкенд API          | Go (gin)                       |
| AI + прокси         | Python (Flask)                 |
| База данных     | Supabase (PostgreSQL)          |
| Рендеринг        | KaTeX, marked.js, highlight.js |
| Редактор кода | CodeMirror                     |
