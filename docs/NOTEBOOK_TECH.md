
# NOTEBOOK_TECH.md

## Концепция

Тетради (Notebooks) — личное и публичное пространство для конспектов. Пользователь создаёт тетради, наполняет их разделами и страницами, использует WYSIWYG-редактор с LaTeX. Тетради можно публиковать в общий каталог, оценивать и закреплять в профиле.

---

## Структура данных

### Тетрадь (Notebook)

- `id` — UUID
- `user_id` — владелец
- `title` — название
- `color` — цвет для отображения (HEX)
- `tags` — массив тегов: subject, level, exam_type, topic, custom
- `is_public` — приватная / публичная
- `views_count` — счётчик просмотров
- `copies_count` — счётчик копирований
- `created_at`, `updated_at`

### Раздел (Section)

- `id` — UUID
- `notebook_id` — FK → notebooks
- `title` — название раздела
- `order_index` — порядок сортировки
- `created_at`, `updated_at`

### Страница (Page)

- `id` — UUID
- `section_id` — FK → sections
- `title` — заголовок страницы
- `content` — TipTap JSON
- `source_task_id` — опциональная привязка к задаче (если сохранена из тренажёра/daily)
- `order_index` — порядок сортировки
- `created_at`, `updated_at`

### Рейтинг (NotebookRating)

- `user_id` — кто оценил
- `notebook_id` — какую тетрадь
- `rating` — 1-5
- `created_at`
- Уникальность: один пользователь = один голос за тетрадь

### Закреплённая тетрадь

- В `rubium_users` поле `pinned_notebook_id` — ссылка на любую тетрадь (свою или чужую)

## Страницы приложения

### 1. Личный каталог (`notebook.html`)

- Сетка карточек тетрадей пользователя (приватные + публичные)
- Карточка: название, цветовая метка, количество разделов/страниц, теги, иконка замка (приватная) или глаза (публичная)
- Кнопка "Создать тетрадь" → модальное окно: название, выбор цвета, теги, переключатель private/public
- У публичных — кнопка копирования ссылки
- Переход по клику: своя → редактор (`notebook-write.html`), чужая → просмотр (`notebook-read.html`)

### 2. Редактор (`notebook-write.html?id=...`)

- Доступен только владельцу тетради
- Левая панель: дерево разделов и страниц
  - Drag-and-drop для изменения порядка
  - Кнопки: добавить раздел, добавить страницу, удалить, переименовать
- Правая панель: TipTap WYSIWYG-редактор
  - Расширения: математика (KaTeX), тулбар (жирный, курсив, заголовки, списки, формула)
  - Два режима: визуальный (дефолт) и исходный LaTeX (переключатель)
  - Автосохранение через 2-3 секунды после прекращения ввода
- AI-панель (сворачиваемая, справа):
  - Inline-автодополнение: серый текст после курсора, Tab — принять
  - Чат с агентом: команды `/explain`, `/formula`, `/example`, `/extend`
- Кнопка "Назад в каталог"

### 3. Просмотр (`notebook-read.html?id=...`)

- Для чужих публичных тетрадей и для своих (режим чтения)
- Левая панель: навигация по разделам и страницам (read-only дерево)
- Правая панель: контент страницы, рендеринг TipTap JSON → HTML + KaTeX
- Кнопка "Редактировать" (только для своих) → переход в `notebook-write.html`
- Кнопка "Сохранить себе" (для чужих) → копирует тетрадь в личный каталог
- Звёздный рейтинг (для публичных) — оценка 1-5
- Кнопка-звезда "Закрепить в профиле" (для любых)

### 4. Публичный каталог (`notebook-community.html`)

- Поисковая строка
- Фильтры: subject, exam_type, level, теги
- Сортировка: по рейтингу, по дате, по популярности
- Карточки: название, 2-3 тега, рейтинг (звёзды), автор (аватар + имя)
- Клик по карточке → модальное окно с подробной информацией:
  - Название, описание, все теги
  - Автор, рейтинг, количество просмотров и копирований
  - Кнопка "Открыть" → `notebook-read.html`

### 5. Профиль (`profile.html` — дополнить)

- Блок "Закреплённая тетрадь"
- Карточка с информацией о закреплённой тетради (название, автор, теги, рейтинг)
- Кнопка "Открепить"

## Редактор

### Технология

- TipTap (ProseMirror) — WYSIWYG-редактор
- Расширения: `@tiptap/extension-math` (KaTeX), стандартный тулбар
- Контент хранится в формате TipTap JSON в БД
- Read-only рендеринг: TipTap в режиме `editable: false` или серверный рендеринг JSON → HTML

### AI-функции (будущая итерация)

- Inline-автодополнение: анализирует последние 500 символов, предлагает продолжение
- AI-чат: контекст — вся тетрадь, предмет, уровень пользователя
- Команды агента: `/explain`, `/formula`, `/example`, `/fix`, `/extend`
- Генерация страницы по запросу (например, "Напиши конспект по теореме Пифагора")
- AI-провайдер: DeepSeek (deepseek-chat для быстрых ответов, deepseek-reasoner для сложных)

## Рейтинг и публичный доступ

- Оценка: 1-5 звёзд
- Один пользователь — один голос
- Средний рейтинг вычисляется агрегацией
- Популярность: комбинация просмотров, копирований, рейтинга
- Копирование тетради: создаётся копия в приватном каталоге пользователя с пометкой источника

| ----------------------------------- | ---------------- | -------------------------------------- |
| Просмотр приватной | Да             | Нет                                 |
| Просмотр публичной | Да             | Да                                   |
| Редактирование        | Да             | Нет                                 |
| Удаление                    | Да             | Нет                                 |
| Копирование              | Да             | Да (только публичные) |
| Оценка                        | Нет           | Да (только публичные) |
| Закрепление              | Да             | Да (любые публичные)   |

## API (для Go-бэкенда)

Эндпоинты префиксом `/api/v1`:

### Тетради

- `GET /notebooks` — список тетрадей пользователя
- `POST /notebooks` — создать тетрадь
- `GET /notebooks/:id` — информация о тетради
- `PUT /notebooks/:id` — обновить (название, цвет, теги, public/private)
- `DELETE /notebooks/:id` — удалить
- `POST /notebooks/:id/copy` — скопировать тетрадь (для чужих публичных)

### Разделы

- `GET /notebooks/:id/sections` — разделы тетради
- `POST /notebooks/:id/sections` — создать раздел
- `PUT /notebooks/sections/:id` — обновить раздел
- `DELETE /notebooks/sections/:id` — удалить раздел
- `PUT /notebooks/:id/sections/reorder` — изменить порядок разделов

### Страницы

- `GET /sections/:id/pages` — страницы раздела
- `POST /sections/:id/pages` — создать страницу
- `PUT /pages/:id` — обновить страницу (контент, заголовок)
- `DELETE /pages/:id` — удалить страницу
- `PUT /sections/:id/pages/reorder` — изменить порядок страниц

### Рейтинг

- `POST /notebooks/:id/rate` — поставить оценку
- `GET /notebooks/:id/rating` — получить рейтинг и количество оценок

### Публичный каталог

- `GET /notebooks/community` — список публичных тетрадей (поиск, фильтры, сортировка, пагинация)

### Профиль

- `PUT /users/me/pinned-notebook` — закрепить тетрадь
- `DELETE /users/me/pinned-notebook` — открепить
