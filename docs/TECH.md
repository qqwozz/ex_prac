
# Exam Trainer — Технологии

Вся техническая часть: стек, архитектура, БД, API, деплой. Без бизнес-логики.

---

## Архитектура

```
Пользователь
  │
  └──→ Python (5080) — фронт + AI
         │
         ├──→ Go (8080) — API + БД
         │       │
         │       └──→ Supabase (PostgreSQL)
         │
         └──→ DeepSeek → OpenAI (фолбэк)
```

| Сервис | Язык | Порт | Зона |
|--------|------|------|------|
| **Backend API** | Go 1.25 / gin | 8080 | БД, проверки, API |
| **AI + Frontend** | Python / Flask | 5080 | Статика, AI-подсказки, генерация |
| **БД** | Supabase (PostgreSQL) | — | Хранение данных |

## Go

### Зона ответственности

- Бэкенд API
- Подключение к Supabase
- Проверка ответов
- Выдача заданий

### Стек

| Компонент | Решение |
|-----------|---------|
| Язык | Go 1.25 |
| Фреймворк | gin |
| БД | Supabase (PostgreSQL) через HTTP API |
| Тесты | `testing` + `httptest` |

### API эндпоинты (реализованные)

| Метод | Путь | Что делает |
|-------|------|------------|
| `GET` | `/health` | Health-check |
| `GET` | `/api/v1/tasks` | Получить задания (фильтры, лимит max=100) |
| `POST` | `/api/v1/check` | Проверить ответ (Go или Python) |

### Middleware

| Middleware | Описание |
|-----------|----------|
| `gin.Recovery()` | Panic recovery |
| `corsMiddleware()` | Whitelist origins |
| `requestLogger()` | Цветное логирование запросов |

### Сервер

| Параметр | Значение |
|----------|----------|
| `ReadHeaderTimeout` | 10s |
| `ReadTimeout` | 30s |
| `WriteTimeout` | 30s |
| `IdleTimeout` | 120s |

### Стартовые проверки

Сервер не запускается, если хотя бы одна проверка не пройдена:

1. Конфигурация (env vars заданы, ключи различаются)
2. Подключение к БД (anon + service key)
3. Checker (все типы заданий)
4. HTTP-эндпоинты

### Таблицы в Supabase

| Таблица | Что хранит | Статус |
|---------|------------|--------|
| `tasks` | Задания (условие, ответ, тип, сложность, тема) | ✅ Создана |
| `attempts` | Попытки учеников (кто, какое задание, ответ, результат) | 🔲 Планируется |
| `users` | Пользователи (подписка, реферал, лимит подсказок) | ✅ Создана |

### Форматы заданий (проверка)

| Тип | Кто проверяет | Как проверяет |
|-----|---------------|---------------|
| Выбор ответа (`choice`) | Go | Точное сравнение строки (регистр-независимое) |
| Ввод числа (`number`) | Go | Сравнение с допуском (±0.01), запятая=точка |
| Ввод строки (`string`) | Go | Нормализация (нижний регистр, схлопывание пробелов) |
| Множественный выбор (`multi`) | Go | Сравнение множеств (порядок неважен) |
| Написание кода (`code`) | Python | Запуск кода + сравнение вывода |
| Текстовый ответ (`text`) | Python | AI-анализ или эталонное сравнение |

**Логика:** Go проверяет простые типы мгновенно. Сложные типы (code, text) пересылаются POST-запросом на Python-сервер (`PYTHON_URL/ai/v1/check`) с таймаутом 15s.

### Определение типа задания

1. Если `task_type` задан в БД — используется он
2. Если `task_type` пуст и `answer` равен `"-"` или пуст — тип = `code`
3. Иначе — тип = `choice`

## Python

### Зона ответственности

- AI-подсказки
- Генерация заданий
- Проксирование запросов в Go

### Стек

| Компонент | Решение |
|-----------|---------|
| Язык | Python |
| Фреймворк | Flask |
| AI | DeepSeek (основной) → OpenAI (фолбэк) |

### AI-подсказки

| Параметр | Значение |
|----------|----------|
| Провайдеры | DeepSeek (основной) → OpenAI (фолбэк) |
| Лимит | 10 подсказок в день |
| Тип | Направляющая мысль, не ответ |
| Механика | По кнопке «Подсказка» |
| Хранение счётчика | Supabase: `users.hints_used_today` |

### Добавление заданий

| Способ | Когда |
|--------|-------|
| Веб-интерфейс (форма) | Добавить 1–5 заданий |
| Загрузка CSV/JSON | Массовая загрузка (100+) |

Формат файла: CSV или JSON, поля совпадают со схемой tasks.

### Генерация заданий

- ИИ создаёт задания для наполнения БД
- Формат: JSON, совпадает со схемой tasks
- Источник: `source = 'ai'`

### Telegram-бот для преподавателей

- Препод управляет заданиями через Telegram
- Бот позволяет: добавлять задания, смотреть статистику учеников
- Бот общается с Go API

| `/api/v1/check` | Go (8080) | Проверить ответ | ✅ |

## Деплой

| Сервис | Порт | Доступ |
|--------|------|--------|
| Go API | 8080 | Внутренний (через Python/nginx) |
| Python + Frontend | 5080 | Публичный |

- Go сервер слушает на `0.0.0.0:8080` (доступен напрямую)
- CORS разрешает запросы с localhost:5500, 5080, 5081, 3000
- В production: nginx проксирует `/api/*` → Go, остальное → Python
