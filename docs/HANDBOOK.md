
# HANDBOOK.md — Рабочая тетрадь и библиотека

## Концепция

Каждый пользователь может создать свою **рабочую тетрадь** — структурированный конспект в формате Markdown с формулами, кодом и изображениями. Тетрадь можно оставить приватной или опубликовать в общую библиотеку. Опубликованные тетради получают рейтинг, просмотры и могут быть сохранены другими пользователями в избранное.

## Создание тетради

### Редактор

- Markdown-редактор с live-превью (как в Notion/Obsidian)
- Поддержка: заголовки, списки, таблицы, код с подсветкой, формулы KaTeX, изображения
- Автосохранение при каждом изменении
- Черновик: можно редактировать сколько угодно до публикации

### Структура тетради

- **Название** — краткое и понятное
- **Описание** — о чём тетрадь, для кого
- **Предмет** — математика, информатика, физика, матан, линал и т.д.
- **Экзамен/курс** — ЕГЭ, ОГЭ, 1 курс, 2 курс
- **Теги** — для поиска (например: #производные #python #алгоритмы)
- **Содержание** — само наполнение в Markdown

### Подпись автора (отображается в конце тетради)

- Имя автора
- Баллы ЕГЭ (если есть)
- ВУЗ, курс, специальность
- Короткое сообщение (опционально)

### Пример:

- Автор: Анна К.
- ЕГЭ: математика 100, информатика 98, русский 96
- МГТУ им. Баумана, ИУ5, 2 курс
- С любовью к сообществу Rubium

## Библиотека (каталог)

### Карточка тетради

- Обложка (автоматически генерируется из содержимого)
- Название
- Автор (кликабельный — переход в профиль)
- Рейтинг (звёзды 1-5)
- Количество сохранений
- Предмет и теги

### Сортировка и фильтры

- По рейтингу
- По дате (новые)
- По популярности (просмотры/сохранения)
- По предмету
- По экзамену/курсу (ЕГЭ, ОГЭ, 1 курс ВУЗа)
- По баллам автора (например: только от авторов с ЕГЭ 90+)

### Модальное окно тетради

При клике на карточку открывается просмотр:

1. Полный рендеринг Markdown-содержимого
2. Описание тетради
3. Информация об авторе (ссылка на профиль)
4. Рейтинг: звёзды + количество оценок
5. Кнопка «Сохранить в избранное»
6. Счётчик просмотров

### Поиск

- По названию
- По описанию
- По тегам
- По имени автора

## Рейтинг и отзывы

### Оценка

- Пользователи ставят оценку от 1 до 5 звёзд
- Один пользователь — одна оценка на тетрадь
- Рейтинг = среднее арифметическое всех оценок
- Отображается: «4.8 (126 оценок)»

### Комментарии (v2, позже)

- Обсуждение тетради
- Вопросы автору
- Благодарности

## Избранное

### Сохранение

- Кнопка «Сохранить» на карточке и в модальном окне
- Сохранённые тетради доступны в профиле
- Можно удалить из избранного

### Моя библиотека

- Раздел в профиле: «Сохранённые тетради»
- Сортировка: по дате сохранения, по рейтингу
- Быстрый доступ к нужным материалам

## Профиль пользователя

### Публичная информация

- Аватар, имя
- «О себе» — короткая история
- Образование: школа → ВУЗ
- Предметы
- Баллы ЕГЭ (опционально, но повышает доверие)
- Мои тетради (созданные)
- Сохранённые тетради

### Статистика автора

- Количество созданных тетрадей
- Суммарный рейтинг
- Общее количество сохранений его тетрадей
- Значок «Проверенный автор» при высоком рейтинге

## Технические детали

### Хранение

- Таблица `handbooks` в Supabase
- Поля: id, user_id, title, description, subject, exam, tags, content (MD), is_published, rating, views, saves_count, created_at, updated_at
- Таблица `handbook_ratings` для оценок пользователей
- Таблица `handbook_saves` для избранного

### Рендеринг

- marked.js — Markdown в HTML
- KaTeX — формулы
- highlight.js — подсветка кода
- CodeMirror — редактор в режиме создания

### API

- `GET /api/v1/handbooks` — список с фильтрами
- `GET /api/v1/handbooks/{id}` — одна тетрадь
- `POST /api/v1/handbooks` — создать
- `PUT /api/v1/handbooks/{id}` — обновить
- `DELETE /api/v1/handbooks/{id}` — удалить
- `POST /api/v1/handbooks/{id}/rate` — оценить
- `POST /api/v1/handbooks/{id}/save` — сохранить в избранное
- `GET /api/v1/users/{id}/handbooks` — тетради пользователя

## Порядок разработки

1. `notebook.html` — редактор тетради (создание/редактирование)
2. `handbooks.html` — каталог (библиотека)
3. Интеграция с профилем
4. Рейтинг и избранное
5. Комментарии (v2)
