
# STORY.md — Сюжетный режим Rubium

## Концепция

Последовательное прохождение тем в формате «глав» и «уровней».
Ученик открывает уровни один за другим, решая задания.
Никаких персонажей, диалогов, сюжета — только структура и прогресс.

---

## Механики

### Уровень

- 3 задания по одной теме
- Сложность: базовая (уровни 1-3), средняя (4-6), высокая (7-10)
- Оценка:
  - 3/3 правильно = 🥇 Золото
  - 2/3 = 🥈 Серебро
  - 1/3 = 🥉 Бронза
  - 0/3 = ❌ Не пройдено (можно переиграть)
- Уровни открываются последовательно
- Пройденные уровни можно переигрывать для улучшения результата

### Глава

- 3-5 уровней, объединённых общей темой
- В конце главы — **босс-уровень**: 5 заданий, таймер 5 минут
- Босс открывается только после прохождения всех уровней главы (хотя бы на бронзу)
- За босса: 3/5+ = глава пройдена, XP x2

### Предметы

- Математика (ЕГЭ профиль)
- Информатика (ЕГЭ) ← **начинаем с этого**
- другие(позже)

## Интерфейс

### Главный экран сюжета

- Верхняя панель: Rubium, XP, аватар
- Выбор главы: горизонтальный скролл (Глава 1, 2, 3...)
- Дорожка уровней: круги с иконками, соединённые линией
  - 🔒 Заблокирован (серый)
  - 🥇🥈🥉 Пройден (золото/серебро/бронза)
  - ▶️ Текущий (фиолетовый, пульсирует)
  - 🏆 Босс (жёлтый, крупнее)
- При клике на уровень — модалка с заданиями
- Нижняя навигация: Главная / Карта / Тренировка / Статистика / Профиль

### Модалка уровня

- Заголовок: «Уровень 2.1: Сортировка»
- Прогресс-бар: 1/3, 2/3, 3/3
- Поле для ответа (или CodeMirror для задач по программированию)
- Кнопка «Проверить»
- После 3 заданий — результат (🥇🥈🥉❌)
- Кнопка «Продолжить» / «Переиграть»

### Босс-уровень

- Таймер обратного отсчёта (5:00)
- 5 заданий подряд
- Результат: пройден / не пройден
- Награда: XP x2

## Данные

### Хранение прогресса (localStorage)

```json
{
  "story_progress": {
    "informatics": {
      "chapter": 1,
      "levels": {
        "1.1": { "status": "gold", "score": "3/3" },
        "1.2": { "status": "silver", "score": "2/3" },
        "1.3": { "status": "locked" },
        "boss_1": { "status": "locked" }
      }
    }
  }
}
```

### API

- `GET /api/v1/tasks?subject=informatics&topic=Переменные&limit=3` — задания уровня
- `POST /api/v1/check` — проверка ответа
- `POST /ai/v1/run` — запуск кода
- `POST /ai/v1/hint` — подсказка (опционально)

## Технические заметки

- Один HTML-файл: `story.html`
- Без бэкенда — только фронт + существующие API
- CodeMirror для задач по программированию
- KaTeX для формул в заданиях по математике
- Все задания берутся из существующей БД (те же, что в тренировке)
- Если заданий по теме меньше 3 — добиваем случайными из той же главы

## Порядок разработки

1. `story.html` — главный экран с дорожкой уровней
2. Модалка с заданиями (3 шт.)
3. Босс-уровень с таймером
4. Сохранение прогресса в localStorage
5. Интеграция с `trainer.html` для переиспользования компонентов
